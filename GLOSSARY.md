# Glossary

- **Assignment**: An accepted photography exercise generated for one concrete situation.
- **Candidate**: A theme, technique, or constraint that may participate in an assignment.
- **Hard constraint**: A condition that must never be violated.
- **Soft preference**: A ranking signal that may be relaxed.
- **Compatibility rule**: Deterministic logic deciding whether a candidate fits the current conditions.
- **Context package**: The smallest set of current sources needed for an Agent task.
- **Agent run**: One attempt by a Coding Agent to complete a benchmark task.
- **Scope violation**: A change outside the task's declared allowed paths.
- **Human rework**: Manual edits needed after the Agent reports completion.
- **Validation gate**: Evidence that must pass before work is accepted.
- **Failure mode**: A recurring pattern explaining how an Agent produces an unsafe or incorrect result.
