# 识别任务 Prompt 中需要 Agent 猜测的空白

学习者能够从“完善函数、处理 invalid 情况并添加测试”这一模糊任务中，识别目标含义、无效情况数量、无效分类标准、输出形态和允许修改范围等未声明信息。这说明学习者已经开始把 Prompt 视为需要消除关键猜测的任务契约，而不只是自然语言请求。

## Evidence

学习者在没有查看参考答案的情况下，主动列出了 Agent 必须自行判断“怎样才算完善”“有多少种 invalid”“某种情况是否 invalid”“成品样式”和“修改范围”。

## Implications

下一步可以学习将这些信息分别放入任务 Outcome、相关 Context、约束与验证证据，并保留真正属于 Agent 的实现自主空间。
