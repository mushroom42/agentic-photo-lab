# 区分任务成功与实验有效性

学习者能够根据修改范围、验证结果和预期行为判断第一次 Agent 任务总体成功，同时识别自动触发的 Skills 使“Prompt v1 单独导致成功”这一因果解释失效。这说明学习者已经开始把交付验收与受控实验结论分开，而不因 100 分可靠性评分就过度声称 Prompt 效果。

## Evidence

面对两文件范围、17/17 测试、零人工返工和自动 Skill/子任务并存的结果，学习者判断任务成功，但明确指出重新运行时需要控制 Skill 干扰。

## Implications

下一步需要选择实验目标：在默认 Codex 环境中把自动 Skills 作为固定背景变量，或建立真正不暴露 Skills 的独立执行环境；不能仅靠任务 Prompt 要求 Agent 忽略更高优先级的运行规则。
